# Qaras

Qaras — локальное веб-приложение для работы с фотографиями лиц. Оно анализирует лица, сравнивает фотографии, выполняет поиск по галерее и сохраняет эмбеддинги в JSON.

Приложение использует [DeepFace](https://github.com/serengil/deepface) и [Beard ViT](https://huggingface.co/dima806/beard_face_image_detection). Проект включает веб-интерфейс, серверные адаптеры и средства запуска в Windows.

## Возможности

- Анализ бороды для каждого найденного лица.
- Дополнительные оценки: видимый возраст, выражение лица, классы `Man`/`Woman` и Timhalland.
- Сравнение двух фотографий. Можно выбрать модель, метрику и порог.
- Поиск похожих лиц в загруженной галерее.
- Извлечение лиц из фотографий.
- Экспорт эмбеддингов в JSON.
- Загрузка до 8 входных фотографий и до 12 фотографий галереи.
- Получение отдельного снимка с веб-камеры.

Доступные детекторы: OpenCV, YuNet, SSD и CenterFace. Режим `skip` обрабатывает всё изображение как лицо. Проверку FasNet можно включить отдельно.

Для сравнения по умолчанию используется SFace. Результаты моделей не подтверждают личность, точный возраст или гендерную идентичность.

## Запуск в Windows

Для установки нужны:

- Python 3.10–3.12.
- Подключение к интернету.
- Свободное место для окружения и моделей.

1. Откройте PowerShell в папке проекта.
2. Запустите установку:

   ```powershell
   powershell -ExecutionPolicy Bypass -File .\install.ps1
   ```

3. Запустите сервер:

   ```powershell
   .\start.cmd
   ```

4. Откройте в браузере `http://127.0.0.1:8011`.

Чтобы остановить сервер, нажмите **Ctrl+C** в его окне.

Чтобы использовать другой порт, запустите:

```powershell
.venv\Scripts\python.exe run.py --port 8012
```

### Установка моделей

Установщик создаёт окружение `.venv` и устанавливает зависимости. Он также загружает Beard ViT из ревизии:

```text
f13217aeacd0a42fee035b903681cbf7fdf1e1e7
```

Веса DeepFace загружаются при первом использовании соответствующей модели. Папка для весов:

```text
.cache/.deepface/weights
```

Окружение и веса моделей не входят в исходную публикацию. Git игнорирует эти файлы.

Для весов моделей действуют отдельные условия использования.

## Timhalland

Timhalland — локальное название классификатора `Race` из DeepFace. В этой версии изменены название и подписи классов. Модель не проходила дополнительное обучение.

Подписи соответствуют выходам модели в следующем порядке:

```text
Asian, Indian, Black, White, East, Latino
```

Новые подписи не меняют исходные классы модели.

Изменения описаны в `vendor/deepface-Timhalland/TIMHALLAND_CHANGES.txt`. Сведения об исходном файле весов находятся в `models/timhalland/weights.json`.

### Подключение весов

Веса Timhalland не входят в публикацию.

Поместите совместимый файл весов по следующему пути:

```text
.cache/.deepface/weights/timhalland_model_single_batch.onnx
```

Используйте файл, на который у вас есть необходимые права.

Для загрузки по URL задайте переменную `TIMHALLAND_WEIGHTS_URL` перед запуском сервера. Укажите адрес совместимого файла из доверенного источника.

Без файла весов модуль Timhalland недоступен.

## Обработка данных

Сервер использует адрес `127.0.0.1`. Приложение обрабатывает фотографии локально в памяти. Оно не отправляет фотографии в Hugging Face.

Временная галерея удаляется после обработки запроса. Браузер хранит выбранные фотографии и результаты до очистки или закрытия страницы.

Ограничения загрузки:

| Параметр | Ограничение |
|---|---|
| Форматы | JPG, PNG, WebP |
| Размер одного изображения | До 10 МБ |
| Разрешение одного изображения | До 16 мегапикселей |
| Общий размер запроса | До 64 МБ |

Сборка предназначена для локальной работы. Для доступа нескольких пользователей настройте развёртывание и управление доступом отдельно.

## Проверка на выборке

Результаты приложения сопоставлены с разметкой MAAD-Face для 96 фотографий из выборки на 200 изображений.

| Признак | Совпадения с разметкой | Доля совпадений |
|---|---:|---:|
| Борода | 84 из 96 | 87,50% |
| Классы Timhalland | 86 из 95 | 90,53% |
| Классы Man/Woman | 79 из 95 | 83,16% |
| Наличие улыбки | 33 из 42 | 78,57% |

Пропущенные прогнозы и неопределённые метки исключены из расчёта. Доля совпадений — число верных ответов, делённое на число проверенных ответов.

Для бороды полнота составила 40%: модель обнаружила 8 из 20 положительных примеров. По разметке положительный класс включает бороду и щетину.

Проверка улыбки оценивает только наличие улыбки. Она не определяет точность остальных классов выражения лица.

Возраст не оценивался: разметка содержит возрастные группы, но не точный возраст.

Разметка MAAD-Face автоматическая и может содержать ошибки. Эти результаты описывают проверенную выборку и не определяют точность на других фотографиях.

## Проверки

Следующие проверки не требуют фотографий или загрузки весов:

```powershell
.venv\Scripts\python.exe -m unittest discover -s tests -v
node --test tests/test_frontend.mjs
.venv\Scripts\python.exe scripts/check_publication.py
```

Для проверки моделей укажите путь к локальной фотографии. Используйте фотографию, на обработку которой у вас есть право.

```powershell
$env:QARAS_SMOKE_IMAGE = 'C:\private\my-test-photo.jpg'
.venv\Scripts\python.exe scripts/smoke_models.py
.venv\Scripts\python.exe scripts/smoke_detectors.py
.venv\Scripts\python.exe scripts/smoke_timhalland.py
```

Скрипты читают фотографию по указанному пути. Они не копируют её в репозиторий.

Проверка Timhalland требует локального файла весов. Остальные необходимые модели загружаются при проверке.

Эти проверки подтверждают работоспособность моделей. Они не измеряют точность на независимом наборе данных.
