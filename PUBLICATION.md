# Публикация исходников

Эта папка — отдельная копия для публикации. Исходный проект и все его локальные фотографии остаются в родительской папке. Публиковать следует репозиторий из **этой папки**, а не из родительского `Finnaly`.

В новую копию не перенесена старая `.git`: поэтому старые коммиты с фотографиями не попадут в новую историю. Для публикации используется отдельный репозиторий GitHub.

## Что включено

- Сервер и веб-интерфейс Qaras, тесты приложения и скрипты запуска.
- Код библиотеки DeepFace с исходной MIT-лицензией и атрибуцией.
- Карточка и настройки Beard ViT с полным текстом Apache-2.0.
- Шрифты Manrope/Literata с оригинальными OFL и графика Qaras.
- Документация источников и локальных изменений.

## Что исключено

- Фото, коллажи и датасеты MAAD-Face/VGGFace2.
- Папки `1-56`, `1-56 correct`, `57-96 correct`, исходные метаданные и отчёты экспериментов.
- Фото и иконки из архива DeepFace, его тестовые датасеты и ноутбуки.
- Все веса, включая Beard ViT, Timhalland и boosted-модели.
- Виртуальное окружение, кэши, журналы, секреты `.env` и история родительского Git.

Файлы перечисленных групп не удалялись из исходной папки. `.gitignore` защищает новую копию от случайного добавления таких файлов после локальной установки и работы приложения. Не обходите эти правила через `git add -f`.

## Проверка перед коммитом и push

Выполняйте из этой папки после установки зависимостей:

```powershell
.venv\Scripts\python.exe scripts/check_publication.py
git status --short
git diff --cached --stat
```

Скрипт проверяет файлы индекса и неигнорируемые новые файлы, а также пути файлов в существующих коммитах: он запрещает фотографии, датасеты, архивы и модельные веса. Для изображений разрешены только `web/qaras-logo.png` и `web/mark.svg`. Также проверяется наличие лицензий. Это проверка состава репозитория; она не устанавливает права на произвольный будущий материал.

При добавлении новой сторонней библиотеки, модели или графики сохраните её лицензию и обновите `THIRD_PARTY_NOTICES.md`. Условия весов, загружаемых при запуске, проверяются отдельно для предполагаемого использования.
